# Identify the group by a short invite code

Invite links were `/join/{groupId}#{token}`: a 22-character group id and a 256-bit token, about 70 characters after the host, which is long to paste into a chat. Links are now `/j#{code}`, where the code is 12 letters and digits (about 71 random bits) that alone identify the group. Guessing any live code among a million groups would still take on the order of 10^15 requests, so no rate limiting is needed; letters and digits only keep the link intact when chat apps detect its end.

Because the link no longer names the group, a D1 table maps a hash of each code to its group, alongside the group index of ADR 0010. The Worker claims the hash before the group's Durable Object stores the code, refuses a code that already opens another group, and keeps rows after a link is replaced, so an old link still reaches its group and is told it was replaced. The Durable Object remains authoritative for whether a code is current, and the code still stays after `#`, so it never reaches a server in a page request. Previews by code use `POST /invites/preview`; joining continues with the group id the preview returns. Groups created earlier keep their long link and 43-character token until someone replaces it, so no migration is needed.
