# Appearance assets

- `instrument-sans.woff2`: variable Instrument Sans, Latin subset, from
  Fontsource (`@fontsource-variable/instrument-sans`),
  https://github.com/Instrument/instrument-sans. Used for body text, labels,
  controls, and titles.
- `geist-mono.woff2`: variable Geist Mono, Latin subset, from Fontsource
  (`@fontsource-variable/geist-mono`), https://github.com/vercel/geist-font.
  Used for amounts and invite links.

Both fonts are distributed under the SIL Open Font License, in
`instrument-sans-OFL.txt` and `geist-mono-OFL.txt`.

All fonts are served locally, without runtime requests to Google or another
font CDN, and the service worker precaches them for offline use.

The favicon in `../icon.svg` comes from the earlier Splitnext app.
